# @deepseek-ai/dsh-client-ui-billing

[English](README.md) | 中文

Web 插件设置区里的 DeepSeek 开放平台余额数字仪表盘卡片。

## 功能

在 `settings.plugin.item` 槽位注册一张卡片，key 为宿主插件服务的 `billing-deepseek` 设置命名空间——只有当宿主装配了 `@deepseek-ai/dsh-billing-deepseek` 时，插件配置页才会显示该卡片。卡片通过连接 API 读取 `billing.usage` RPC，渲染余额读数：账户可用状态、当前/赠送/充值余额、平台累计消费、本地快照推导的今日/本周/本月消费，以及快照数。每 30 秒自动刷新（仅可通过修改 `REFRESH_INTERVAL_MS` 调整），并提供手动刷新按钮；刷新失败时保留上次成功值并显示原因。

卡片只读：只渲染宿主 API 的数据，不修改任何设置。当宿主未装配计费插件时，RPC 返回 `ok: false` 及原因，卡片直接展示。

## 渲染

- 加载中 →「加载中…」；失败 →「获取失败：<原因>」；未装配 → 显示宿主原因；历史为空 →「暂无计费数据」。
- 余额行使用 `¥` 符号与两位小数；无法归因的窗口（窗口开始前无快照）显示「—」。
- 底部显示最近刷新时间与刷新按钮（刷新进行中禁用）。

## 导出形态

函数/命名空间插件：导出 `inject` / `apply`，无 default；浏览器半部通过 `exports["./client"]` 按 `dsh.client` 声明分发。Node 半部为空 `apply`，使 Loader 行可解析。

## Model Experience

该卡片是面向用户的设置界面，从不进入模型视野，也不产生会话事件，因此没有工具 schema、token 影响或 KV-cache 影响需要记录。

## 已知限制与后续工作

- **纯数字**——无图表；时间序列只能通过工具文本报告查看。
- **固定 30 秒节奏**——刷新间隔是模块常量而非部署配置；修改需编辑 `REFRESH_INTERVAL_MS`。
- **数据新鲜度在宿主侧**——卡片展示宿主插件已轮询或按需抓取的历史；`refresh` 本身在宿主历史为空时并不直接命中平台（原样呈现宿主报告）。
- **单币种展示**——报告使用宿主插件配置的币种或平台首个币种。
